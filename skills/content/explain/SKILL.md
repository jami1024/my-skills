# Explain Clearly

统一处理学习类请求。先判断用户需要一页解释，还是一条可执行的学习路径；不要让同一请求同时触发多个学习 Skill。

## 模式选择

| 用户目标 | 模式 | 默认产物 |
|---|---|---|
| 理解一个概念、机制、产品或文章 | 概念解释 | Markdown 讲解、例子、术语表、自测题 |
| 学习一门语言、框架、工具或完整主题 | 项目教程 | 学习计划、主线项目、分步代码、验证和排错 |
| 只问一个具体问题 | 概念解释 | 直接回答，不强行生成完整教程 |
| 逐行理解代码库、查 bug 或做 review | 不使用本 Skill | 使用代码分析或审查流程 |

默认输出 Markdown；用户明确要求网页时才输出 HTML。

## 先确定教学任务

开始前明确：

- **目标**：读者学完能解释、判断或完成什么；
- **基础**：读者已经知道什么；
- **边界**：本次不覆盖哪些高级细节；
- **假设**：版本、运行环境、输入材料和未确认事实。

只询问会改变答案的问题。信息不足但风险低时，明确假设后继续。

## 概念解释模式

适合短回答、一页教学材料和“讲人话”。按主题取舍以下结构：

```markdown
# 主题
## 学习目标
## 先说结论
## 一个类比（说明类比的失真边界）
## 它实际怎么工作
## 最小例子
## 常见误解与边界
## 术语表
## 自测题或下一步
```

写作顺序：

1. 先给结论，不从术语定义开头；
2. 用一个熟悉的类比，再说明它哪里不准确；
3. 把机制拆成不超过 5 个连续步骤；
4. 关键术语首次出现时给白话解释；
5. 用最小例子验证机制；数字、人物和事实来自输入或明确标为假设；
6. 说明常见误解、适用边界和什么时候不该用；
7. 结尾给 2–3 个自测问题或具体练习。

不要为了“完整”堆砌历史、背景和无关术语。

## 项目教程模式

适合新语言、框架、工具或需要系统练习的完整主题。

### 1. 先给学习计划

复杂主题先展示或生成 `{topic}-plan.md`，包含：

- 学习目标和完成标准；
- 前置知识、版本和环境；
- 按顺序排列的阶段与知识点；
- 主线项目及每阶段新增能力；
- 示例、练习和验证命令。

用户确认计划后再展开长教程；小主题可以直接生成，但仍需先列出目标和步骤。

### 2. 设计一条主线

围绕一个小项目推进。每一步都说明：

1. 要完成的动作；
2. 要修改的文件或运行的命令；
3. 应该看到的结果；
4. 这一步引入的概念；
5. 失败时如何定位和恢复。

主体让读者动手；设计取舍、历史背景和替代方案放到“设计说明”，不要混入每一步。

### 3. 编写与验证示例

- 代码与目标版本匹配；
- 新文件给出完整内容，增量步骤说明修改位置；
- 运行命令、预期输出和实际行为一致；
- 能运行时执行 format、lint、test、build 或语言对应命令；
- 不能运行时明确标记“未运行”，不声称已验证；
- 示例中的数据、版本和事实来自输入、官方资料或明确假设。

### 推荐教程结构

```markdown
# {主题} 学习教程
> 完成后你能：{可验证目标}

## 你将构建什么
## 前置准备
## 学习路线
## 第一步：{动作}
### 修改或运行
### 你应该看到
### 这一步学到了什么
## 第二步：{动作}
## 综合项目与验证
## 常见问题与排错
## 练习
## 设计说明（可选）
## 下一步
```

不要强制添加固定数量的附录、FAQ 或替代方案。

## 通用写作规则

- 开头给可验证的结果，不从百科式背景开始；
- 一次只引入当前步骤需要的概念；
- 一条主路径优先，替代方案只在影响决策时说明；
- 每一步都有可见结果或明确的验证方式；
- 术语首次出现时给白话解释；
- 排错建议对应具体现象和原因；
- 示例可运行时实际验证，不能验证就诚实标注；
- 使用简洁自然的中文，中英文之间留空格，代码注释保持简短；
- 不使用空泛的“至关重要”“深入探讨”“精彩旅程”等 AI 套话；
- 结尾给具体下一步，不用泛泛鼓励收尾。

## 质量清单

### 概念解释

- [ ] 目标、读者基础和边界明确；
- [ ] 先说结论，再解释机制；
- [ ] 类比标明失真边界；
- [ ] 例子中的事实、数字和数据有来源或明确是假设；
- [ ] 包含误解、边界和自测题。

### 项目教程

- [ ] 主线项目足够小，能在合理时间完成；
- [ ] 版本、依赖、环境和假设已标注；
- [ ] 每一步都有动作、结果和验证；
- [ ] 最终项目有完整运行路径；
- [ ] 练习有明确目标和检查方式；
- [ ] 未运行的命令和未验证的输出已标注。
