## 有意砍掉的内容及原因

原文并非都跟 agent 行为有关；本 skill 只保留能改变 agent 行为的规则：

- 职业/动机框架（"读码是程序员底层能力""读码让你获得经验"）——受众是人类学习者。
- 把写博客当作写作练习、长期英文/写作能力建议——人生建议，不是读码流程。
- "产出是改进学习的反馈"这一学习理论论证——保留为规则（必须产出），去掉论证。

## ground truth 与静态分析的界限

**最重要的一个转化决定**：原文强调情景分析，是因为*观察到的执行路径是 ground truth*，静态阅读只是假设。对 agent 而言这一点尤其关键——否则它的结论会严重依赖推测性的模式匹配。

规则：报告里每条承重结论都必须标注

- **[verified]** —— 经运行/调试/测试/场景复现观察到，或
- **[static]** —— 仅由阅读推断。

若绝大多数结论都只能是 `[static]`，要么去搭环境（Phase 1），要么在报告中如实说明（本地化新增：给出比例统计）。

## 本地化补丁（相对上游）

1. Phase 1 的**预算上限**：防止"编译跑起来"吞掉整个任务预算。
2. 报告要求里的 **`[verified]`/`[static]` 比例**：防止在不可运行的环境里产出格式完整、实则全为静态推断的报告。
