# Skill 标题

## 目标

说明这个 skill 要解决的问题，以及不负责解决什么。

## 输入

## 工作流程

1. 第一步：写出可验证的动作。
2. 第二步：写出判断条件和交付结果。
3. 第三步：执行质量检查。
