# React Skill Eval

这些用例用于人工回归 `react-best-practices` 的路由、项目适配和输出质量。它们不是运行时代码，不会被默认加载。

## 运行方式

1. 使用干净会话，加载 `skills/dev/react-best-practices`；
2. 逐条发送 `cases.md` 中的输入；
3. 对照每条的“必须满足”和“失败信号”记录结果；
4. 修改 `SKILL.md` 或相关参考后重新执行受影响用例。

## 通过标准

- 新项目先得到架构决策，不直接生成固定脚手架；
- 已有项目先读取并复用现有依赖和配置；
- 不无理由引入路由、状态库、UI 库或样式方案；
- 输出包含边界状态、测试和验证命令；
- 推荐方案说明依据和代价，而不是只给单一技术名。
